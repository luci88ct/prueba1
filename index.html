Automatización gratis

Como no quieres gastar nada, la mejor combinación es usar una web estática y tirar de fuentes públicas o embeds oficiales, evitando backend propio y APIs de pago.

1

YouTube automático

Usa el feed público del canal y conviértelo con rss2json.com o un workflow de GitHub Actions para regenerar un JSON cada pocas horas.

2

Directo en Twitch

El embed de Twitch es el método más simple. Si además quieres cambiar un badge a “en directo”, puedes consultar la API de decapi.me o un JSON estático regenerado desde GitHub Actions.

3

Reels de Instagram

Instagram no ofrece una solución pública cómoda y gratis para listar todo automáticamente en web estática; la opción más fácil es insertar reels destacados manualmente o usar un agregador gratuito con límites.

Subirla gratis

  • Crea un repositorio en GitHub y sube este archivo como página principal.
  • Activa GitHub Pages desde la rama main.
  • Cuando tengas dominio propio, cambia parent=localhost por tu dominio.
  • Si prefieres interfaz más simple, también puedes arrastrarla a Netlify Drop.

Qué debes editar

  • Usuario exacto de Twitch, YouTube e Instagram.
  • Embeds reales de reels o posts destacados.
  • Texto, colores y enlaces a Discord, TikTok o donaciones si quieres ampliarla.
  • Opcional: conectar un JSON generado por GitHub Actions para tarjetas automáticas de vídeos.

Plantilla pensada para Jairobiix, optimizada para publicación gratuita y fácil mantenimiento. El único punto delicado es Instagram: para auto-listado real sin pagar, suele requerir soluciones con límites o edición manual.
